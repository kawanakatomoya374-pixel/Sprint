## 5. 宣言・スコープ・名前解決・評価順

### 5.1 スコープ

- スコープはレキシカルかつ**ブロック単位**である。関数本体、`if`/`elif`/`else`、`while`、`for`、`try`、`catch`、`case`の各ブロックが新しいスコープを作る。
- module top-levelはmodule scopeである。
- 同一スコープ内での同名の`let`/`const`/`func`/`class`/import束縛の重複はコンパイルエラー。
- 内側スコープでのshadowingは許可する。builtin名をshadowした後、そのスコープではbuiltinを参照できない。

### 5.2 宣言

| 宣言 | 意味 |
|---|---|
| `let x` | `nil`で初期化 |
| `let x = e` | `e`を評価して初期化 |
| `const x = e` | 初期化後、束縛の再代入不可（コンパイルエラー`ConstError`）。値の内部変更は可 |
| `func f(...)` | 関数値を束縛（§9） |
| `class C:` | class値を束縛（§10） |

- 変数は宣言より前に参照できない（コンパイルエラー`NameError`）。例外は次の2つ:
  - **module top-levelの`func`と`class`**: module内のどこからでも参照できる（相互再帰可）。これらはmodule本体の実行前に生成される（§14.5）。
  - **関数の自己再帰**: `func f`の本体から`f`を参照できる。
- module top-levelの`let`/`const`を、その宣言文が実行される前に（関数経由で）読むと実行時`NameError`（「未初期化」）。
- 代入`x = e`は既存の束縛への代入である。宣言されていない名前への代入はコンパイルエラー`NameError`。関数内からmodule変数へ代入する場合も、名前解決でmodule束縛が見つかればそのまま代入できる（`global`宣言は不要であり、存在しない）。
- import束縛、`const`、module top-levelの`func`/`class`束縛への代入はコンパイルエラー`ConstError`。

#### 5.2.1 分割代入（2.1）

```sprint
let [a, b] = e                 # array
let [head, ...rest] = e        # 末尾の ...rest は e.slice(位置) の結果
let {x, y: why} = e            # table（またはinstance）。key: 束縛名
const [p, q] = e               # const も同様（すべての束縛が const）
```

- 意味は、隠れた一時変数（ユーザーからは参照できない）への1回の評価と、各名前の通常の宣言への**脱糖**である。`let [a, b] = e` は「`e`を1回評価し、`a = tmp[0]`、`b = tmp[1]`」、`let {x, y: why} = e` は「`x = tmp.x`、`why = tmp.y`」、`...rest` は「`tmp.slice(位置)`」に等しい。
- したがって失敗は対応する通常の操作の失敗である: 要素が足りなければ`IndexError`、arrayでない値への`[...]`パターンは`TypeError`、`...rest`は新しいarrayを割り当てる（A）。**余った要素は無視される**。tableパターンで存在しないkeyは、`tmp.key`と同じ規則に従う。
- 束縛名は同一スコープの通常の宣言と同じ規則（§5.1）に従い、重複する名前はコンパイルエラー。パターンの要素は名前だけで、入れ子のパターンやデフォルト値は書けない（入れ子の構造には`match`を使う）。パターンは空にできない。個数の上限は256。
- `...rest`は最後の要素としてのみ書ける。tableパターンのkeyにキーワードを使うときは`key: 名前`の形で束縛名を与えなければならない。
- 分割代入は宣言（`let`/`const`）にのみ書ける。既存変数への代入（`[a, b] = ...`）は書けない。`export`は付けられない。

#### 5.2.2 多重代入（2.3）

```sprint
a, b = b, a            # 値を同数並べる: 入れ替え
x, y = pair            # 右辺が1つなら添字で分解: x = pair[0], y = pair[1]
arr[0], t.k = 1, 2
```

- すべての右辺を左から右へ評価して隠れた一時変数へ入れてから、左辺を左から右へ代入する（`a, b = b, a`が入れ替えになる理由）。右辺が1つなら`tmp[0]`、`tmp[1]`…を代入し、要素が足りなければ`IndexError`。余った要素は無視される。
- 左辺は名前・メンバ・添字（通常の代入の対象）。個数は最大16。右辺の個数が1でも左辺と同数でもなければ`ParseError`。宣言（`let a, b = ...`）にはならない（分割代入は§5.2.1）。複合代入（`a, b += ...`）はない。

### 5.3 名前解決

識別子は次の順にコンパイル時に解決し、各識別子に解決結果を付与する。Compilerは実行時に名前文字列で変数を探してはならない。

1. 現在の関数のlocal（内側ブロックから外側へ）
2. 外側関数のlocal（upvalueとしてcapture）
3. module束縛（import束縛を含む）
4. builtin（prelude、§15.1）
5. どれでもなければコンパイルエラー`NameError`

メンバ名（`x.name`）の存在は実行時に検査する。ただしimportしたmoduleのメンバ（`m.name`、`m`がimport束縛の場合）はコンパイル時に検査し、exportされていなければコンパイルエラー`NameError`。

### 5.4 評価順（正本）

**Sprintの評価順は例外なく左から右である。**

| 構文 | 順序 |
|---|---|
| 二項演算 | 左operand → 右operand（`and`/`or`/条件式は短絡） |
| 呼出し`f(a, b)` | `f` → `a` → `b` → 呼出し |
| spread`f(a, ...xs)` | `f` → `a` → `xs` → 展開 → 呼出し |
| メソッド呼出し`o.m(a)` | `o` → メソッド検索 → `a` → 呼出し |
| 代入`a[i] = v` | `a` → `i` → `v` → 格納 |
| 代入`o.k = v` | `o` → `v` → 格納 |
| 複合代入`a[i] += v` | `a` → `i` → 現在値の読出し → `v` → 演算 → 格納。`a`と`i`は1回だけ評価 |
| array literal | 要素を左から |
| table literal | key1 → value1 → key2 → value2 … 同じkeyが重複した場合、後の値が先のkeyの位置を更新する |
| 条件式`x if c else y` | `c` → `x`または`y`の一方だけ |
| `defer o.m(a)` | 登録時に`o` → メソッド検索 → `a`を評価。呼出しはブロック終了時 |
| default引数 | §9.2 |
