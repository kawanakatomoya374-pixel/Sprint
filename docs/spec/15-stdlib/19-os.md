### 15.19 window / vfs / proc / wm（2.6、同梱module）

Sprint自身で「OSごっこ」ができるようにする層。すべて**Sprintで書かれた同梱module**で、整数演算のみ・仮想時計のため、同じ入力は同じ結果とピクセルを生む。

#### window（プラットフォーム層）

`gui.App`と画面の間の層。**Backend**が1つのウィンドウを持ち、入力イベント（`gui.mouse_move()`などと同じdict）を渡し、完成したフレーム（`gfx` canvas）を表示し、マウスポインタ形状を受け取る。

| 項目 | 仕様 |
|---|---|
| `Backend` | 基底クラス。`open(w, h, title)` `poll()`（届いたイベントのarray）`present(canvas)` `set_cursor(name)` `get_clipboard()` `set_clipboard(s)` `set_title(s)` `close()`、`closed` `name` `width` `height` |
| `Headless` | 常に存在するメモリ上の表示。`feed(ev)` `feed_all(evs)`でイベントを積む。`present`したフレームの`hash()`を`hashes`（直近`keep`=16個）に、最後のフレームを`last`に、ポインタ形状を`cursor`に、フレーム数を`frames`に保持。`screenshot(path)`でPNG保存。クリップボードは`clip` |
| `register(name, factory)` / `backends()` / `available(name)` | バックエンドの登録と一覧。`factory()`は`Backend`を返す |
| `open(w, h, title="", backend="headless")` | ウィンドウを開く。登録のない名前は`ValueError`（利用可能な一覧つき） |
| `run(app, win, max_frames=-1, idle=nil)` | イベントを`app.dispatch`し、変化があれば描画して`present`する。`quit`イベント・`app.running`がfalse・窓が閉じる・`max_frames`枚表示・イベントが尽きる（`idle(app, win)`がtrueを返す間は続行）で終わる。表示したフレーム数を返す。Headlessでは`app.show_cursor`が立ち、ポインタはソフトウェア描画される |

**この版にネイティブのバックエンド（X11・Win32・Cocoa・framebuffer）は含まれない。** `register`で外部が差し込む前提のインターフェースだけがある（Cホスト側の実装は未着手）。

#### vfs（メモリ上のファイルシステム）

`FS()`: 階層ファイルシステム。パスは`/`区切りで、相対パスは`cwd`から解決。一覧は整列済みで決定的。失敗は`error("OSError", ...)`。

`mkdir(path, parents=false)` `write(path, data)` `append` `read` `ls(path=".")` `stat(path)`（`kind` `size` `mtime`）`rm(path, recursive=false)` `cp` `mv` `chdir` `walk(path="/")` `exists` `is_dir` `is_file` `dump()` / `load(text)`（JSON）。関数: `normalize(path, base="/")` `basename` `dirname` `join`。

#### proc（カーネルとシェル）

- `Kernel(fs=nil)`: 協調マルチタスクのカーネル。プロセスは`main(sys, args)`の関数でcoroutineとして走る。`spawn(name, main, args=[])`→pid、`send(pid, msg)`、`kill(pid)`、`alive`、`exit_code`、`ps()`（`[pid, name, state]`）、`step(ms=1)`（仮想時計を1msずつ進め、実行可能な全プロセスに1スライス）、`run_all(limit)`、`now`、`stdout`。
- `Sys`（プロセスから見たカーネル）: `pid` `fs` `now()` `print(s)` `sleep(ms)` `yield_now()` `recv()`（メッセージが来るまで待つ）`send(pid, msg)` `spawn(...)` `kill(pid)` `exit(code)`。
- `Shell(kernel)`: 組込みコマンド `ls cd pwd cat echo write mkdir rm [-r] cp mv ps kill tree help` と`install(name, main)`で追加するプログラム（`/bin/<name>`にも登録）。`run(line)`が出力文字列を返し、エラーは`cmd: <OSError: ...>`形式の文字列になる。`prompt()`は`"<cwd> $ "`。

#### wm（デスクトップ環境）

`gui`の上のウィンドウシステム。`Desktop(w, h)`は`gui.App`を継承し、`show_cursor`が既定で真。

- `Frame`（トップレベル窓）: タイトルバー（ドラッグ移動、ダブルクリックで最大化/復元）、閉じる・最大化・最小化ボタン、右下のリサイズグリップ。角丸の**当たり判定形状**（§15.14）を持ち、タイトルバーとグリップはcontentが重なっていても枠が受ける。
- `Desktop`: `open_window(title, x, y, w, h, content)`、`activate(f)`（前面へ）、`minimize` `toggle_max` `close_frame`（`on_close(f)`がfalseを返すと閉じない）、`top()`、`wins`（背面→前面）、`work_area()`、`add_icon(label, x, y, on_open)`（ダブルクリックで起動）、`set_clock(s)`、タスクバー（窓ごとのボタン。クリックで復元/前面/最小化）。背景は`Wallpaper`。
- `Terminal(shell, w, h)`: スクロールバック、入力行、履歴（Up/Down）、Enterで`shell.run`。`lines` `input` `print_line(s)`。
