### 15.20 typed（2.29）

`import typed`。要素が**1種類の機械数**に固定された、長さ固定の配列。要素は箱詰めせずに（1要素1〜8バイトで）持つので、通常の`array`（1要素16バイト）より小さく、要素の読み書きに型タグの検査がいらない。数値計算・バイト列・画素バッファ向け。ネイティブオブジェクトで、`type(x)`は`"native"`、エラー文などでの型名は`typed.f64`のようになる。

| 生成 | 要素 | 読んだときの型 |
|---|---|---|
| `typed.i8(x)` `typed.i16(x)` `typed.i32(x)` `typed.i64(x)` | 符号付き整数（8/16/32/64ビット） | int |
| `typed.u8(x)` `typed.u16(x)` `typed.u32(x)` | 符号なし整数（8/16/32ビット） | int |
| `typed.f32(x)` `typed.f64(x)` | 浮動小数点（単精度/倍精度） | float（`f32`は倍精度へ広げて返す） |

`x`は長さ（int、`0`以上。全体で2 GiBまで。超えるとValueError）か、要素を写す`array`。長さを渡すと全要素が`0`（`0.0`）で、**A**（1回の割り当て）。`array`を渡すと各要素に下記の書き込み規則を適用する（違反はTypeError）。

**添字と長さ**
- `a[i]`・`a[i] = v`: `i`はintで`0 <= i < len(a)`。範囲外はIndexError、非intはTypeError（`array`と同じ）。割り当てなし（—）。
- `len(a)`: 要素数（O(1)）。長さは変えられない（`append`などはない）。
- `for x in a` / `for i, x in a`: `array`と同じく要素（と添字）を順に返す。長さは変わらないので、反復中の変更検査はない。
- `a == b`は同一性の比較（`array`と同じく内容比較ではない）。

**書き込み規則（MUST）**
- 整数型: 値はintでなければならない（`bool`・`float`・`nil`はTypeError）。範囲外の値は**下位ビットに切り詰める**（`typed.u8`に`300`を書くと`44`、`typed.i8`に`200`を書くと`-56`。CやJavaScriptの型付き配列と同じ）。
- `f64`: intまたはfloat（intはfloatへ変換する）。`f32`: 同じく変換したうえで単精度へ丸める（最近接偶数丸め）。それ以外はTypeError。
- NaNと無限大はそのまま保存される。

| メソッド | 割当 | 仕様 |
|---|---|---|
| `a.fill(v)` | — | 全要素に`v`を書く（書き込み規則を適用。長さ0でも`v`の型は検査する） |
| `a.copy()` | A | 同じ型の新しい配列 |
| `a.slice(start, end=len(a))` | A | `array`の`slice`と同じ範囲規則（範囲外はIndexError、`start > end`はValueError）で、同じ型の新しい配列 |
| `a.to_array()` | A | 通常の`array`へ（要素は読んだときの型） |
| `a.kind()` | A | `"i8"`〜`"f64"`の文字列 |
| `a.set_from(src, offset)` | — | `src`（`typed`の配列または`array`）の全要素を`offset`から書く。はみ出す（`offset + len(src) > len(a)`、`offset < 0`）とIndexError。型が違う`typed`からは要素ごとに書き込み規則を適用する。同じ型どうしの重なりは`memmove`と同じ |

- すべてのメソッドはユーザーコードを呼ばない。
- 決定性: 同じ入力は同じ結果になる（浮動小数点の丸めはIEEE 754の最近接偶数）。
- メモリ: 割り当ては`max_heap_bytes`に数える。上限を超える場合は何も変更せずにMemoryError（致命的）。
- 埋め込みAPIの`sp_native_data`で取り出せるnative objectではない（内部型）。

**JIT（§17.14）**: ホットループでは、添字の読み書きが型タグ・クラスのガードと範囲検査のあと、要素へ直接アクセスする機械語になる（読みは`TY_INT` / `TY_FLT`のレジスタ値）。`for x in a`もJITされる（要素の取り出しはヘルパ呼び出し）。インライン化されるメソッド・関数の本体の中の添字（`self.d[i]`など）も同じ機械語になる。ガードが外れた（別の種類の配列に変わった、範囲外、型違いの書き込み）ときは、通常どおりインタプリタが同じ命令を再実行してエラーを出す。

`print(a)`や`to_string(a)`は他のnative objectと同じ`<native typed.f64 #ID>`の形になる。中身を見るには`a.to_array()`を使う。
